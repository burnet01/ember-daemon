Ember

Set up a node with one command.

Paste it on a Linux machine and it installs everything. Then open the panel on your PC and the node is already there.

1

Run this on your Linux machine

If the machine isn't on Tailscale yet, it installs Tailscale and shows a link to log in.

curl -fsSL https://burnet01.github.io/ember-daemon/install.sh | sudo bash
2

Open Ember Panel on your PC

Use a device logged in to the same Tailscale account, and the node appears by itself.

What the command does

  • Installs nftables, iproute2, bsdtar and Tailscale if they're missing.
  • Downloads the daemon, checks its checksum and starts it as a service.
  • Makes your Tailscale login the only one allowed to manage the node.
  • Checks for new releases every 2 minutes and installs them right away.

Fully automatic, with no login link

Add a Tailscale auth key to the command and nobody has to touch anything:

curl -fsSL https://burnet01.github.io/ember-daemon/install.sh | sudo bash -s -- --auth-key tskey-auth-YOUR-KEY

On GitHub Actions, keep the key in a repository secret. Anything written in a workflow file is readable by anyone who can see the repo.

- run: curl -fsSL https://burnet01.github.io/ember-daemon/install.sh | sudo bash -s -- --auth-key "$TS_AUTHKEY"
  env:
    TS_AUTHKEY: ${{ secrets.TS_AUTHKEY }}
  • Use a single-use key, because a command you type stays in your shell history.
  • Don't use a key with tags, or also add --owner your@login, because a tagged machine has no owner to detect.
  • An Actions runner only lasts as long as its job, so the node goes away when the job ends.

Good to know

  • It needs 64-bit x86 Linux with systemd and cgroup v2, which most current distros have.
  • When an update installs, it waits for backups to finish. Running servers then restart, so players get disconnected for a moment. If the new version won't start, the old one is put back.
  • To turn updates off, run sudo bash -s -- --no-auto-update instead of sudo bash.
  • Management only works over Tailscale, so finding this page doesn't give anyone access to your node.
